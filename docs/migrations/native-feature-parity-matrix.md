## Purpose

This document defines the native behavior that the Tauri client must preserve
before the Android, Apple, or Windows product UI source can be removed. It
records two different kinds of evidence:

1. the immutable native baseline at the commit above; and
2. the current, mutable Tauri implementation on the migration branch.

The baseline repository and continuity details are recorded in
[Frozen native baseline](native-baseline.md). Core method semantics are
recorded separately in the
[Core--Tauri contract matrix](core-tauri-contract-matrix.md). This matrix is
about reachable product behavior, platform interaction, and removal evidence.

## Status rules

| Status | Meaning |
|---|---|
| **Implemented** | A reachable product flow is connected from UI through the typed command boundary to Core or the platform service, and relevant automated checks pass. |
| **Partial** | Some production layers or tests exist, but the full reachable flow or required evidence is incomplete. |
| **Pending** | No complete implementation and passing evidence exist yet. Declarations, DTOs, generated bindings, controllers, or test doubles alone do not count. |
| **Blocked** | Completion requires a named external prerequisite such as a signing identity, target OS runner, device, or packaging decision. Missing code is **Pending**, not **Blocked**. |

Native test references below prove that test source exists. They do not claim
that a test was executed in this Tauri audit. A command is counted as passing
only when its result is listed in
[Current Tauri evidence](#current-tauri-evidence).

## Union policy

The Tauri target is the union of useful, reachable behavior across the four
native clients, not their intersection:

- iOS has no reachable character Library or content-package Import flow. Its
  provider catalog JSON picker is a different settings workflow.
- macOS has no conversation-list UI. Selecting a character opens its most
  recent conversation or creates one.
- Windows likewise auto-selects the most recent applicable conversation and
  has no explicit conversation chooser or new-conversation action.
- Android and iOS contribute explicit conversation selection and creation.
- iOS and macOS contribute the shared branch, mode, edit, regenerate, and
  remove message experience that Android and Windows do not expose.
- Every native client contributes provider lifecycle behavior, but their
  credential, input, accessibility, and platform lifecycle contracts differ.

Consequently, the shared Tauri product must offer both Library/Import and
conversation selection on every supported platform, as well as the complete
Apple shared Chat actions. A feature missing from one frozen native surface is
not permission to omit it from that platform's Tauri client.

## Removal authority

No native product source is removable today. A platform table is not an
independent deletion authorization:

1. every row in the production-release gate in
   [Tauri mainline migration](tauri-mainline-migration.md) must have recorded
   passing evidence;
2. every applicable platform row above must pass;
3. the frozen private repository, annotated tag, build instructions, and
   synthetic seed harnesses must remain cloneable and verified;
4. all supported platform CI must be green on the same removal candidate;
5. no runtime, release job, or required contract test may reference the native
   app being removed; and
6. source removal must be a separate reviewed commit.

A mirror, a file count, an API declaration, a source-only unit test, or one
host's successful build never satisfies this authority.
